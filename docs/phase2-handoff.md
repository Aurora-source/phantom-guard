## Interface

`phantomguard.eval.attack_adapter.attack_source` is the shared evaluation/demo
adapter. It expects:

```python
# src/phantomguard/attack/scenarios.py
def create_attacker(cfg, baseline, *, attack_type, level, seed, train_segments,
                    replay_provenance, unseen_segments, motion_case,
                    replay_variant, run_index):
    ...  # Phase 2-owned scenario construction

# src/phantomguard/attack/injector.py
class AttackedSource:
    def __init__(self, source, attacker, labels_path=None): ...
    def __iter__(self): ...  # ordinary Frame values only
```

An existing contributor API can be adapted without changing the attacker:
`--provider module:function` accepts `(source, cfg, baseline, **context)` and
returns a frame source. `context` contains the same keyword arguments above plus
`labels_path`. The adapter passes copies of config/baseline so contributor code
cannot mutate defender configuration. The attacker never receives the defender
object, learned windows, verdicts or evaluation labels.

`seed` is the authoritative effective seed. For evaluation it is generated by
`numpy.random.SeedSequence([configured_seed, run_index]).generate_state(1)[0]`;
`run_index` is metadata, and must not derive the seed again. The viewer passes the
selected seed directly. Both entry points record seeds in output identities.

## Emitted frames and labels

- Yield `Frame(can_id, data: bytes, timestamp_ticks)` in final arrival order.
  Encode forged object/header bytes through the established frame functions.
  Genuine and forged frames enter the same cycle assembler and decoder.
- Write a CSV sidecar with **one row per final emitted frame**, indexed from zero:
  `frame_index,is_attack,attack_id,attack_type,level`. Clean rows may have empty
  attack metadata; attacked rows must have all three metadata values. Complete
  coverage includes forged headers, malformed frames and unknown CAN IDs.
- Indices must reflect insertions and overwrites in the final stream. Slot ID,
  CSV row index and original-frame index cannot substitute for final indices.
- A forged header belongs to an attack instance but does not become a forged
  object. Duplicate-slot objects retain separate final indices. Labels remain
  solely in the sidecar; the viewer has no ground-truth overlay.
- The evaluator detects missing/extra/duplicate sidecar indices and fails the
  run explicitly. It distinguishes a scene/cycle alert from an alert on the
  exact forged object. A scene alarm may be an incidental clean alarm; no paired
  counterfactual attribution is claimed.

## Owner decisions to preserve

A2 repairs header counts, counters, cadence and slot uniqueness. It is allowed
to fail range-order and burst-contiguity checks, which require A3+ awareness.
Do not strengthen A2 to satisfy an old blanket “A2 passes protocol” test.

T4 A0/A1 append a same-slot forged frame alongside the genuine frame. T4 A2+
replace the genuine frame in place. This is the documented strong overwrite
capability, not track deletion or a bus suppression model.

Use the learned `baseline['rr_scale']['value']` for physical motion. Distance
units and `tick_seconds` remain assumptions. Match observed quantisation, held
values, integer RCS and serialised CAN burst timing using the existing real-data
pools. Static/moving T1 and T2 cells are requested separately; T3/T4 need moving
tracks. T3 A0–A2 are explicitly unsupported because recorded moving replay is
documented as inherently A3/A4. Raise `UnsupportedAttack` for unsupported cells
or unavailable source material instead of silently substituting a scenario.

## Replay provenance

`replay_provenance` is `earlier_stream`, `training`, or `unseen`.
`replay_variant` is `exact` or `translated`.

- Earlier stream: only already-emitted eligible history may be the replay source.
- Training: only the supplied defender-training segment identities.
- Unseen: only explicitly supplied evaluation segments, separate from defender
  library construction. In time-block evaluation these are another recording's
  held-out test portion; that recording also has a seen training portion. In LOSO
  the supplied source is the wholly held-out recording, even when evaluating a
  validation portion of the other files. Run rows distinguish these scopes.

The adapter rejects unseen segments overlapping defender training segments.
Defender replay libraries are built solely by `train.py` from training segments;
unseen attacker material never enters those libraries.

## Validation and remaining dependencies

Once the modules/API are available, run:

```text
python scripts/run_attack_eval.py
python scripts/replay_demo.py --file onePersonMovingFrontAndBack.csv --attack T1 --level A2 --export
python -m pytest -q
```

The evaluator requests all configured seeds × repetitions, time-block test and
four LOSO folds, each layer, fusion and leave-one-layer-out ablations. It writes
run/instance/clean/exclusion CSVs, a manifest and `docs/results/summary.md`.
Missing Phase 2 produces a blocked matrix and a nonzero exit, while independent
clean evaluation can complete. Fixture tests exercise frame integration and
PNG/GIF export; they are never used as a headline attacker or attack benchmark.

Current instance denominators are **observed emitted attack IDs**. All observed
undetected and EOF-touching instances remain in denominators; EOF-touching
instances are conservatively marked right-censored. Planned instances that never
emit a frame cannot be reconstructed from the required sidecar. Phase 2 must
provide a separate schedule/lifecycle manifest before those can be counted as
scheduled-but-unobserved or distinguished from genuinely completed EOF attacks.
No such instances are silently asserted to be detected or undetected.

AE selection is fixed for NumPy CPU deployment before attack testing. IF is an
offline comparison on exactly the captured online AE windows. Do not select a
model or threshold using attack-test performance.

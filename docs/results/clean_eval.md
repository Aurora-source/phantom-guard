# Clean-data evaluation (no attacks)

Generated by `scripts/run_clean_eval.py`. Every number below is produced by that script.

**Scope.** False positives on held-out *clean* data only. No attacker is implemented in this repo yet, so detection rate by attack type and level, time-to-detect, and AUROC of the learned score are **not reported**. A layer that raises no false positives here has *not* been shown to catch anything.

- Definitions: *flagged* = an object-cycle with at least one reason code from the enabled layers. *Alerting* = after fusion (hard reason, or 3 of the last 5 cycles of the track flagged). *Alert events* = number of times a track (or the cycle stream) enters the alert state. Minutes come from header timestamps × `tick_seconds` (0.0001, unverified assumption).
- Thresholds: `configs/baseline.json` (time-block) and `data/processed/baseline_loso_*.json` (LOSO), learned from train (AE thresholds: validation). The test split was not used for any threshold.
- The ROI (range <= 15.0) applies to the kinematic, replay and learned layers; protocol checks apply to every frame.
